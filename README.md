# 仓颉·认知舵标

将用户提供的书籍章节、论文段落或长文本，整理成忠于原文、便于自学、可继续追问的中文学习材料。

## 能做什么

- 先梳理文本结构，再提取概念、证据、案例、反例和容易误解之处。
- 用通俗中文解释，同时保留关键原文术语与科学准确性。
- 对实验、数据和案例只陈述原文支持的信息；原文未提供的细节会明确标出。
- 按固定的“三击流”组织输出，并在结尾提供后续精读选项。
- 支持深入解释术语、继续处理下一章（需提供文本）、情景题自测，以及难句或图表解释。

## 适用场景

当你提供了具体章节、论文部分或文本片段，并希望进行精读、拆解、总结、解释或知识提炼时使用。它不根据书名猜测内容，也不代替 OCR 或文档预处理；无法读取来源内容时，会要求提供可访问的文本或文件。

## 输出流程

1. **全景透视**：用大白话说明核心问题，列出 3-5 个概念及其逻辑关系，并指出有原文依据的误读风险。
2. **实证还原**：选取重要实验、数据、案例、模型或论证链，解释假设、做法和结果。没有实验的文本不会被伪装成实验研究。
3. **内容重构**：给出两个忠于原文的选题标题、一句核心表达和一个有文本依据、可观察的行动建议。
4. **后续导航**：以“仓颉·认知舵标”选项引导深入术语、继续下一章、情景自测或解释难句图表。

## 安装

将本目录放入 Codex 的技能目录：

```text
~/.codex/skills/cangjie-cognitive-compass/
```

确保 `SKILL.md` 位于该目录根部。`agents/openai.yaml` 提供 Codex 界面显示名称、简介和默认提示词。安装后可在请求中使用 `$cangjie-cognitive-compass` 调用。

## 使用示例

```text
$cangjie-cognitive-compass 请精读我上传的第三章，并指出每个结论对应的原文依据。
```

```text
$cangjie-cognitive-compass 请解释这段论文中的实验设计；没有交代的样本信息请明确标出。
```

## 仓库结构

```text
cangjie-cognitive-compass/
├── SKILL.md              # 技能定义、来源审计、阅读流程、输出规范与质量检查
├── README.md             # 功能介绍、安装与使用说明
├── STRUCTURE.md          # 文件结构和内部设计说明
└── agents/
    └── openai.yaml       # Codex 界面元数据和默认提示词
```

## 当前限制

- 结论范围受用户实际提供且可读取的材料限制。
- “下一章”只有在其文本可访问时才能继续处理。
- 输出中的媒体选题和行动建议也必须受原文约束，不应扩写成来源没有支持的观点。
